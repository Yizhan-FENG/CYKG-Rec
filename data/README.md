# Data directory

This repository intentionally contains no educational content, interaction logs, graph exports, embeddings, or experiment outputs.

Use the following ignored directories locally:

```text
data/raw/        licensed source archives and source snapshots
data/processed/  derived, de-identified, reproducible processing outputs
```

Never upload copyrighted textbooks, worksheets, OCR text, student data, or generated derivatives unless you have the explicit right to redistribute them.
